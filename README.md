# dotfiles

Personal macOS (Apple Silicon) development environment managed with
[chezmoi](https://www.chezmoi.io/), synced to
[github.com/hungle45/dotfiles](https://github.com/hungle45/dotfiles).

## What is managed

| Target | Source | Notes |
|---|---|---|
| `~/.zshrc` | `dot_zshrc` | oh-my-zsh + powerlevel10k; sources `~/.zsh_secrets` (not in repo) |
| `~/.zprofile` | `dot_zprofile` | Homebrew shellenv, OrbStack |
| `~/.p10k.zsh` | `dot_p10k.zsh` | powerlevel10k prompt config |
| `~/.tmux.conf` | `dot_tmux.conf` | self-contained (no plugin manager) |
| `~/.gitconfig` | `dot_gitconfig` | user identity |
| `~/.ideavimrc`, `~/.vimrc` | `dot_ideavimrc`, `dot_vimrc` | IdeaVim / vim |
| `~/.config/nvim/` | `dot_config/nvim/` | LazyVim, incl. `lazy-lock.json` (pinned plugin versions) |
| `~/Library/Application Support/com.mitchellh.ghostty/config` | `private_Library/…` | Ghostty config; `private_` reflects macOS's default `0700` on `~/Library` dirs |
| `~/.pi/agent/settings.json` | `dot_pi/agent/settings.json` | Pi agent settings, packages, theme |
| `~/.config/opencode/opencode.json` | `dot_config/opencode/opencode.json` | OpenCode config |

**Deliberately not managed:** `~/.zsh_secrets` (API keys, `0600`, recreate by hand),
`~/.pi/agent/auth.json` (credentials), shell histories, caches (`~/.cache`,
`~/.zcompdump*`), Neovim data (`~/.local/share/nvim` — plugins install themselves
from `lazy-lock.json`), `node_modules`, `Brewfile.lock.json` (generated, volatile),
`.idea/` (IDE-local).

## Set up a new Mac

```sh
# 1. Install Xcode Command Line Tools and Homebrew
xcode-select --install
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
eval "$(/opt/homebrew/bin/brew shellenv)"

# 2. Install chezmoi and apply all managed configs
brew install chezmoi
chezmoi init --apply hungle45        # clones this repo to ~/.local/share/chezmoi

# 3. Recreate secrets by hand (never committed):
#    ~/.zsh_secrets   (chmod 600; see "Secrets" below)

# 4. Install packages from the Brewfile
brew bundle --file ~/.local/share/chezmoi/Brewfile

# 5. Open a new shell; oh-my-zsh / powerlevel10k are cloned by
#    run_once_bootstrap-zsh-frameworks.sh during step 2.

# 6. Start nvim once — lazy.nvim installs plugins pinned in lazy-lock.json.
```

### Brewfile notes

- `brew bundle` also installs the `go` and global `npm` tool sections; the `go`
  tools require Go to be present first. Go itself is *not* brew-managed on this
  machine — it comes via the `GOROOT` toolchain referenced in `dot_zshrc`.
- Pi extension packages (`pi-notify`, `pi-rewind`, `pi-subagents`,
  `@agentmemory/agentmemory`) are intentionally omitted: Pi installs them from
  its own `settings.json`.
- `Brewfile.lock.json` is generated by `brew bundle` when installing. It is
  **not tracked** (see `.gitignore`): it records volatile version state; the
  Brewfile is the source of truth.

## Day-to-day workflow

chezmoi's source of truth is `~/.local/share/chezmoi` (a Git clone of this repo).

```sh
# EDIT a managed file — edits the SOURCE copy, then re-apply:
chezmoi edit ~/.zshrc            # or: chezmoi edit --apply ~/.zshrc
chezmoi apply                    # sync all source -> home

# EDIT directly in your home directory, then pull the change back:
chezmoi add ~/.zshrc             # overwrite source with the live file
chezmoi re-add                   # re-add ALL modified managed files at once

# REVIEW before applying (never blind-apply):
chezmoi diff
chezmoi apply --dry-run --verbose

# What is / is not managed:
chezmoi managed
chezmoi unmanaged
chezmoi ignored

# Add something new, e.g. another tool's config:
chezmoi add ~/.config/newtool    # then: git add/commit/push in ~/.local/share/chezmoi

# Remove something from management (keeps the live file unless --rm):
chezmoi forget ~/.config/newtool
```

### Synchronize with GitHub

```sh
cd ~/.local/share/chezmoi
chezmoi git add .
chezmoi git commit -m "update dotfiles"
chezmoi git push
# On another machine:
chezmoi update          # git pull + apply
```

## Secrets & machine-specific settings

- **Secrets** live in `~/.zsh_secrets` (`0600`, untracked, sourced by `dot_zshrc`):
  API keys are never placed in managed files, templates, or Git history.
  `~/.pi/agent/auth.json` is likewise unmanaged — Pi re-authenticates itself.
  If you later want secrets synced securely, use chezmoi's `encrypt_` files
  (age/GPG) or the 1Password/Bitwarden integration instead of plaintext.
- **Machine-specific settings**: currently all managed configs are identical-safe
  across machines. `dot_zshrc` uses `$HOME`-relative paths; a few genuinely
  external-volume paths (GoLand app, `MINIKUBE_HOME`, the `learn` alias) are kept
  literal and only work where `/Volumes/External` exists. `dot_pi/agent/settings.json`
  references a workspace package by relative path; Pi tolerates it being absent.
  When real per-machine divergence is needed, convert the file to a `.tmpl`
  template keyed on `{{ .chezmoi.hostname }}` or `.chezmoi.os`.
- **Ghostty**: managed in place at macOS's default path. `private_Library/…` in
  the source is intentional (chezmoi records `0700` on the standard macOS dirs).
- The chezmoi config file itself (`~/.config/chezmoi/chezmoi.toml`) is
  machine-specific and unmanaged; this checkout uses the default source dir.

## Recovery

If a config breaks, the previous versions are in Git history:
`cd ~/.local/share/chezmoi && chezmoi git log -- <path>`, or use
`chezmoi diff` to see what an apply would change. `~/.zshrc.bak-*` files are
pre-chezmoi manual backups kept in `$HOME` (untracked).
